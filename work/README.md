## 🛠️ How these were sanitized

Each piece went through:
1. **Pattern-based scrubbing** — real names → `[COLLEAGUE]`, corporate emails → `[EMAIL_REDACTED]`, internal system names → role placeholders
2. **Multi-pass leak verification** — automated regex scan across 7 leak categories; zero hits in final files
3. **Asset extraction** — large assets (video) moved to `assets/` folder, referenced via `<src>` not inlined
